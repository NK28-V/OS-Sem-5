Aho-Corasick Multi-Pattern Antivirus Simulation

Educational user-space simulation. Not a real antivirus, not a kernel driver.

1. Teaching Demonstration: "ushers" Trace

What this shows: Trie, failure links, output inheritance on ["he","she","his","hers"].
OS Concept: Automaton state representation, failure jump paths, amortized O(1) state transitions.
Not run yet - run python run.py demo

2. Experiment E1: Signature Scaling

What this shows: Invariance of AC throughput as k scales vs Naive O(k*n) decay.
OS Concept: Complexity decoupling from memory; Trie memory scaling.
Not run yet - run python run.py e1

3. Experiment E2: Chunk Streaming & I/O Buffering

What this shows: Streaming scan across block sizes without backtracking or boundary misses.
OS Concept: I/O buffering trade-offs: system call count vs buffer allocation.
Not run yet - run python run.py e2

4. Experiment E3: On-Access Interception Pipeline

What this shows: Open latency across Sync, Cached, and Async interception modes.
OS Concept: Blocking IPC, caching (path, mtime, size), race conditions, and Fail-Open vs Fail-Closed reliability.
Not run yet - run python run.py e3

Simulation Limitations

  • Python Overhead: Pure Python loop limits speed; C/Rust engines run at gigabytes/sec.
  • User-Space Interception: Real OS antivirus uses kernel minifilters / fanotify in ring 0.
  • Synthetic Data & Cache: Random bytes and repeated reads reflect OS page cache benefits.

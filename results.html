Aho-Corasick in Antivirus Scanning

How scan time grows with the number of virus signatures, for four algorithms.

Educational user-space simulation. Not a real antivirus, not a kernel driver.

What was measured

An antivirus checks every scanned file against k signatures. Naive, KMP and Boyer-Moore search for one signature at a time, so they read the file k times. Aho-Corasick puts all signatures into one automaton and reads the file once. We scanned the same 524,288 bytes of data for k = 10, 100, 1,000, 10,000, 100,000. A single-pattern algorithm is skipped when its estimated time would exceed the time budget.

Result

  • Aho-Corasick scan time grew 14.0× while k grew 10,000× (10 → 100,000).
  • Naive grew 112.7× for a 100× increase in k (k = 10 → 1,000).
  • KMP grew 135.7× for a 100× increase in k (k = 10 → 1,000).
  • Boyer-Moore grew 124.0× for a 100× increase in k (k = 10 → 1,000).
  • Automaton memory reached 609.1 MB at k = 100,000 (1,852,717 states).
  • All algorithms that ran found exactly the same matches.
